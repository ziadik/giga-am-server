# 🎙️ GigaAM Server

Сервер распознавания **русской речи** на **GigaAM v2 (RNNT)** с ускорением на **GPU (CUDA)**.

> Автор: **Зядик Дмитрий Сергеевич** | [https://ziidik.ru/](https://ziidik.ru/)

## ✨ Особенности

- 🇷🇺 **Только русский** — оптимизирован под русскую речь
- 🎯 **96–98% точность** (Whisper small: 80–85%)
- ✅ **Пунктуация и заглавные буквы** — автоматически
- 🚫 **Нет галлюцинаций** — модель не зацикливается на тишине
- ⏱ **Таймкоды** — каждый сегмент с временными метками
- 🚀 **GPU CUDA** — RTX 1660 Super и выше
- 📦 **Без нарезки, без обрезки тишины, без фильтров** — GigaAM сам всё делает

## 🖥️ Требования

- **Node.js** 14+
- **Python** 3.9–3.11
- **CUDA Toolkit** 12.x
- **FFmpeg**
- **NVIDIA GPU** 4+ GB VRAM (рекомендуется 6+)
- **RAM**: 8+ GB
- **Диск**: ~2 GB (модель GigaAM)
